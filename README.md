# MC_IKIT

## 1. О проекте

**Название проекта:** Афиша молодежного центра ИКИТ СФУ.

**Назначение системы:** система предназначена для структурирования и учёта мероприятий молодежного центра, а также для анализа деятельности центра.

## 7. Установка и запуск

Для локального запуска проекта необходимо выполнить следующие команды:

```bash
# Установка зависимостей
pip install -r requirements

# Переход в папку Django-проекта
cd MCIKIT

# Применение миграций
python manage.py migrate

# Запуск локального сервера
python manage.py runserver
```

## 8. Проверка работы

После запуска сервера необходимо открыть в браузере адрес:

http://127.0.0.1:8000/

Главная страница приложения должна открыться в браузере.
