# Результаты проверок качества

## Проверка конфигурации Django

В локальной копии Python-исходников выполнены `python manage.py check` и
`python manage.py check --deploy` с временным ключом и тестовым доменом.
Ошибок уровня Error нет. При проверке развертывания получены `security.W005` и
`security.W021`, поскольку область HSTS и предварительную загрузку нужно согласовать
для реального домена. Локальная копия без ресурсов также дала `staticfiles.W004`;
в GitHub каталог `MCIKIT/static` присутствует.

Ruff подключён как форматтер, линтер и статический анализатор импортов и имён.
Полный отчёт до и после форматирования и исправлений заполняет разработчик по
логам CI. Установка Ruff в локальном окружении была недоступна из-за доступа к индексу пакетов.
