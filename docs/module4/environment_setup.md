# Рабочее место разработчика

Проект использует Python 3.11, Django и SQLite. Для практической работы выбрана
Visual Studio Code с расширениями Python (`ms-python.python`), Pylance
(`ms-python.vscode-pylance`), Ruff (`charliermarsh.ruff`) и EditorConfig
(`EditorConfig.EditorConfig`). Команды установки окружения приведены в [README](../../README.md).

Откройте в VS Code файл [MC_IKIT.code-workspace](../../MC_IKIT.code-workspace) и установите рекомендованные расширения.
Выберите интерпретатор проекта через `Python: Select Interpreter`,
назначьте Ruff форматтером для Python, включите `Format On Save` и выберите тему
`Dark Modern`. Стандартное сочетание форматирования на Windows
`Shift+Alt+F` можно назначить в `Keyboard Shortcuts` для `Format Document`.

Корневые настройки проекта задают отступы, правила Ruff, параметры покрытия и
Git-хуки. После `python -m pre_commit install` хук проверяет форматирование и
линтинг изменённых Python-файлов. При ошибке исправьте файлы, добавьте их в индекс
и повторите коммит. Чтобы подготовить применение форматтера ко всему проекту,
запустите `python -m ruff format MCIKIT` из корня.

Для итогового PDF приложите скриншот рабочего места участника команды со списком
расширений и выбранным интерпретатором. Локальные предпочтения IDE фиксируются здесь;
свидетельство установки на компьютере участника добавляется после настройки.
