# Тесты и покрытие

Начальная локальная проверка на копии Python-исходников выполнила три сценария
`MCIKIT.test_health`. Все три прошли:

- `GET /health` возвращает 200 и JSON со статусом `ok`.
- `POST /health` возвращает 405 и заголовок `Allow: GET`.
- Неавторизованный запрос к профилю перенаправляется на `users:login` с параметром `next`.

Эти тесты Django выполняются без базы. Полный запуск и проценты покрытия строк и ветвей
для `users`, `add_event` и ядра Django-проекта берутся из того же коммита,
в котором интегрированы тесты команды. CI выводит сводку и прикладывает HTML
как артефакт `module4-coverage`. Локальная проверка трёх сценариев не измеряла покрытие.
