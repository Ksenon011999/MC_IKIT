## 4. Анализ модели данных

Проверены модели Django в приложениях `users` и `add_event`.

Выявлены и рассмотрены семь основных сущностей:

1. `User` — пользователи и их роли.
2. `Event` — мероприятия.
3. `EventOrganizer` — организаторы мероприятий.
4. `EventRating` — оценки и отзывы.
5. `ExtraInfo` — дополнительные вопросы.
6. `UserAnswer` — ответы пользователей.
7. `Choice` — варианты ответов.

Проверено наличие ER-диаграммы, содержащей все семь сущностей. В README добавлено краткое описание модели данных.
