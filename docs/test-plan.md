# План тестирования

## Цель
Проверить работоспособность health-check endpoint
и корректность применения конфигурации приложения.

## Чек-лист проверки

- [ ] Приложение запускается без ошибок.
- [ ] GET-запрос по адресу `/health` выполняется успешно.
- [ ] Сервер возвращает HTTP 200.
- [ ] Ответ содержит `{"status": "ok"}`.
- [ ] Конфигурация приложения загружается корректно.

## Ожидаемый результат

Приложение запускается без ошибок, health-check
возвращает ожидаемый ответ, конфигурация применяется
корректно.
