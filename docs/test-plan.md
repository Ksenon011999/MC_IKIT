# План тестирования

## 1. Цель тестирования

Проверить работоспособность health-check endpoint и корректность применения конфигурации приложения.

## 2. Объект тестирования

- Django-приложение MC_IKIT.
- Health-check endpoint `/health`.
- Файл конфигурации `config/config.yaml`.

## 3. Область тестирования

В рамках проверки необходимо убедиться, что:
- приложение запускается без ошибок;
- health-check endpoint доступен;
- сервер корректно обрабатывает GET-запросы;
- возвращается ожидаемый HTTP-статус и JSON-ответ;
- конфигурация приложения загружается и применяется корректно.

## 4. Методы тестирования

- Ручная проверка запуска приложения.
- Проверка health-check endpoint с помощью GET-запроса, анализ HTTP-статуса и содержимого JSON-ответа.
- Проверка применения параметров конфигурации.

## 5. Чек-лист проверок

- [ ] Приложение запускается без ошибок.
- [ ] GET-запрос по адресу `/health` выполняется успешно.
- [ ] Сервер возвращает HTTP 200.
- [ ] Ответ содержит `{"status": "ok"}`.
- [ ] Конфигурация приложения загружается корректно.

## 6. Критерии успешного прохождения

Тестирование считается успешным, если приложение запускается без ошибок, health-check возвращает HTTP 200 и ожидаемый JSON-ответ, а конфигурация приложения применяется корректно.
